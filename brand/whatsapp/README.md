# WhatsApp profile pictures

1024×1024 PNGs, made for WhatsApp's circular crop. The icon stays inside the circle with margin. The `.svg` files are the editable sources.

| File | Look | Use |
|---|---|---|
| `softiba-whatsapp-ink.png` | Navy, cyan icon | **Recommended.** Most on-brand, clear in light and dark mode |
| `softiba-whatsapp-signal.png` | Cyan gradient, white icon | Stands out most in a chat list |
| `softiba-whatsapp-paper.png` | Cream, cyan icon | Light, calm alternative |
| `softiba-whatsapp-wordmark.png` | Navy, full "softiba" logo | Only where the picture is shown large; unreadable at chat-list size |

The icon uses heavier strokes than the website mark so it stays legible at about 40px.
